# Characters trackers

Page des fiches de personnages, hébergée avec GitHub Pages.

- `index.html` : la page (tes fiches d'origine, inchangées)
- `css/style.css` : ton CSS d'origine, tel quel — `css/popup.css` : le style du pop-up
- `js/fiches-original.js` : tes scripts d'origine — `js/ajout-fiche.js` : le pop-up
- `data/fiches.json` : les fiches ajoutées via le pop-up (une entrée par personnage, modifiable à la main)

Pour ajouter une fiche : « Nouvelle fiche » en bas à droite. Pour en corriger une : « Modifier cette fiche » (la fiche affichée à l'écran), ou la liste déroulante en haut du formulaire.
Une fiche modifiée est enregistrée dans `data/fiches.json` et remplace l'ancienne à l'affichage ; le HTML d'origine d'`index.html` reste intact.
Sur un nouvel appareil : ouvrir le « lien d'installation » (à copier depuis le panneau « Enregistrement sur GitHub »).
